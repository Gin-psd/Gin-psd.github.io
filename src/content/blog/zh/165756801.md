### 1\. 本周学习与收获

本周系统学习了 Python 语言中的 for 循环语句、字符串的索引与切片、字符串的常用方法（如统计个数、转大小写等）、序列类型中的列表、映射类型中的字典等相关知识，涵盖了 for 语句的格式与语法、列表的概念与运用、字典的概念与运用。

#### 1.1 程序控制结构：for 循环与 while 循环

for 语句通过遍历可迭代对象建立循环，与 while 循环的区别在于：for 循环是次数确定的遍历，而 while 循环是次数不确定的循环。

简单来理解，for 循环就像一个拿着名单点名的人，他知道总共有多少人，会一个一个按顺序叫，叫完名单上所有人就结束；而 while 循环就像一个在等公交车的人，他不知道车什么时候来，但他知道一个规则：“只要车还没有到，我就一直等”。

```python
# for 循环：次数确定的遍历
for i in range(5):
    print(f"第 {i} 次点名")

# while 循环：次数不确定，满足条件才停止
import random
bus_arrived = False
while not bus_arrived:
    print("继续等车...")
    bus_arrived = random.choice([True, False])
```

#### 1.2 组合数据结构：序列类型与映射类型

序列类型是一种按顺序排列的元素集合，包括列表和元组；而字典属于映射类型，是一种键值对的集合，每个键都对应一个值，通过键可以快速访问值。

简单来说，列表是有序的，字典是无序的。列表就像是一排带编号的格子，而字典就像是用标签找东西的收纳盒。

```python
# 列表：有序，按下标访问
students = ["张三", "李四", "王五"]
print(students[0])  # 张三

# 字典：键值对，按键访问
scores = {"张三": 90, "李四": 85, "王五": 92}
print(scores["张三"])  # 90
```

#### 1.3 字符串的索引、切片与常用方法

字符串支持索引和切片操作，还提供了丰富的内置方法，如统计个数、转换大小写等。

```python
text = "Hello Python"

# 索引
print(text[0])    # H
print(text[-1])   # n

# 切片
print(text[0:5])  # Hello
print(text[6:])   # Python

# 常用方法
print(text.count("o"))   # 统计字符出现次数
print(text.upper())      # 转大写
print(text.lower())      # 转小写
```

### 2\. 实战案例

#### 2.1 用 for 循环打印三角形

```python
# 打印直角三角形
for i in range(1, 6):
    print("*" * i)
```

输出结果：

```
*
**
***
****
*****
```

#### 2.2 字符串的综合运用

```python
# 统计一句话中每个单词的长度
sentence = "Python is a powerful language"
words = sentence.split()
for word in words:
    print(f"{word}: {len(word)} 个字符")
```

#### 2.3 列表的运用

```python
# 遍历列表并计算总和
numbers = [10, 20, 30, 40, 50]
total = 0
for num in numbers:
    total += num
print(f"总和: {total}")  # 150
```

#### 2.4 字典的运用

```python
# 遍历字典的键值对
student_scores = {"张三": 90, "李四": 85, "王五": 92}
for name, score in student_scores.items():
    print(f"{name} 的成绩是 {score}")
```

### 3\. 遇到的难题与困惑

#### 3.1 for 循环与 while 循环的区分不够清晰

在判断一个案例该用 for 循环还是 while 循环时容易出错。核心判断标准是：**循环次数是否确定**。如果明确知道要循环多少次，用 for 循环；如果循环次数取决于某个条件是否满足，用 while 循环。

#### 3.2 列表对象和字符串的常用方法记得不够清楚

列表和字符串都有很多内置方法，容易混淆。建议整理成对照表，通过反复练习加深记忆。

#### 3.3 列表和字典的混合使用不够清晰

在实际应用中，经常需要列表和字典配合使用，例如列表中嵌套字典，或者字典的值是列表。需要多练习这类组合场景。

```python
# 练习：for 与 while 叠加使用
# 外层 for 控制行数，内层 while 控制每行输出
for i in range(1, 4):
    j = 0
    while j < i:
        print("*", end="")
        j += 1
    print()  # 换行
```

输出结果：

```
*
**
***
```
