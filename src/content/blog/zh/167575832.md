### 一、本周学习收获

本周的学习内容较为丰富，主要围绕异常处理、模块与包的调用，以及人工智能基础认知展开，同时正式开启了项目一的开发工作。

#### 1\. 异常处理

异常处理是 Python 编程中保障程序健壮性的重要机制。本周系统学习了 `try`、`except`、`else`、`finally` 等关键字的配合使用，理解了异常捕获的基本流程：先尝试执行可能出错的代码，若发生异常则进入对应的 `except` 分支进行处理，`else` 在无异常时执行，`finally` 无论是否异常都会执行，常用于资源释放。

```python
try:
    num = int(input("请输入一个整数："))
    result = 100 / num
except ValueError:
    print("输入的不是有效数字！")
except ZeroDivisionError:
    print("除数不能为零！")
else:
    print(f"计算结果为：{result}")
finally:
    print("程序执行结束。")
```

通过异常处理，程序在遇到错误时不会直接崩溃，而是能够给出友好的提示并继续运行，这对后续开发管理系统时的数据校验非常有帮助。

#### 2\. 模块与包的调用

模块与包的调用分为两类：一是内部模块（Python 自带的 `sys`、`os`、`json`、`random` 等），二是外部模块（需要通过 `pip install` 安装的第三方库，如 `pyttsx3`、`requests` 等）。

```python
# 内部模块调用
import os
import sys
import json

# 外部模块调用（需先安装：pip install pyttsx3）
import pyttsx3
```

理解了两者的区别后，在项目开发中就能根据需求灵活选择：基础功能优先使用内部模块，特殊功能（如语音播报）则引入外部模块。

#### 4\. 调用大模型实现对话交互

阶段二的核心任务之一，是学会如何在 Python 中调用大模型，形成对话交互的模式。关键步骤包括：

-   注册获取 API-Key；
-   通过 `requests` 库向大模型接口发送请求；
-   接收响应并解析返回结果。

整个过程本质上是一个「请求—响应」的循环：客户端将用户输入封装为请求发送给服务端，服务端处理后返回结果，客户端再解析展示。

```python
import requests

api_key = "你的API-Key"
url = "https://api.example.com/v1/chat/completions"

headers = {
    "Authorization": f"Bearer {api_key}",
    "Content-Type": "application/json"
}

data = {
    "model": "gpt-3.5-turbo",
    "messages": [{"role": "user", "content": "你好"}]
}

response = requests.post(url, headers=headers, json=data)
result = response.json()
print(result["choices"][0]["message"]["content"])
```

#### 5\. 项目一：英雄信息管理系统

国庆假期前，雷老板布置了项目一——开发一个管理系统，要求包含基础功能：增删改查以及保存，并可自行添加特色功能增添创意。

我的项目是**英雄信息管理系统**，使用 Python 开发，采用本地 txt 文件保存英雄数据，不需要数据库。能够完成英雄信息的新增、查询、修改、删除功能，额外集成了本地语音播报功能，在完成操作后语音朗读结果，提升交互感。

```python
# 项目核心结构示意
from storage import load_heroes, save_heroes
from operations import show_heroes,add_hero,delete_hero,update_hero,search_hero



def print_menu():
    print("\n===== 王者荣耀英雄管理系统 =====")
    print("1. 查看所有英雄")
    print("2. 添加英雄")
    print("3. 删除英雄")
    print("4. 修改英雄")
    print("5. 查询英雄")
    print("6. 保存到文件")
    print("7. 重新加载文件")
    print("0. 退出")


def main():
    heroes = load_heroes()

    while True:
        print_menu()

        try:
            choice = input("请选择：").strip()
        except KeyboardInterrupt:
            print("\n程序被中断，自动保存后退出。")
            save_heroes(heroes)
            break

        if choice == "1":
            show_heroes(heroes)
        elif choice == "2":
            add_hero(heroes)
        elif choice == "3":
            delete_hero(heroes)
        elif choice == "4":
            update_hero(heroes)
        elif choice == "5":
            search_hero(heroes)
        elif choice == "6":
            save_heroes(heroes)
        elif choice == "7":
            heroes = load_heroes()
        elif choice == "0":
            save_heroes(heroes)
            print("退出系统。")
            break
        else:
            print("输入无效，请重新选择。")


if __name__ == "__main__":
    main()
```

这个项目不仅考验我们对所学知识的综合运用能力，也提升了我们对业务需求的理解能力——如何把一个「管理系统」的需求拆解为清晰的功能模块，并用代码逐一实现。

### 二、遇到的难题与困惑

#### 1\. 异常处理的覆盖范围

在编写异常处理时，我常常困惑于「到底要捕获哪些异常」。捕获太少，程序可能因未预料的异常而崩溃；捕获太多，又可能掩盖真正的逻辑错误。目前我的做法是：先捕获最常见的 `ValueError` 和 `FileNotFoundError`，再根据测试反馈逐步补充。

#### 2\. 外部模块的安装与环境问题

调用外部模块时，偶尔会遇到 `ModuleNotFoundError`，原因往往是模块未安装或安装到了不同的 Python 环境中。我通过 `pip install 模块名` 解决，但有时需要确认当前使用的是哪个 Python 解释器。

#### 3\. API-Key 的请求与响应理解

调用大模型时，对「请求—响应」的完整流程理解还不够透彻，尤其是请求参数的构造（如 `messages` 的格式、`model` 的选择）以及响应数据的解析（如 `choices` 的层级结构）。这部分需要多写几个示例来加深理解。

#### 4\. txt 文件的数据持久化

在英雄信息管理系统中，如何设计 txt 文件的存储格式（如每行一个英雄、字段用逗号分隔），以及如何保证读写时数据不丢失、不乱码，是我在项目开发中遇到的主要困惑。目前采用「逐行读取 + 按分隔符解析」的方式，但还需要考虑文件不存在时的初始化处理。

#### 5\. 语音播报功能的集成

集成 `pyttsx3` 语音播报时，遇到的主要问题是初始化引擎后朗读速度偏慢，以及在某些环境下没有声音输出。我通过调整语速参数和检查音频设备来解决。

### 三、错题反思与总结

#### 1\. 异常处理、模块与包、调用大模型的错题反思

在异常处理、模块与包以及调用大模型的学习中，我认识到自己在这些进阶知识点上仍存在薄弱点，主要集中在以下几个方面：

-   **异常处理**：对 `try`、`except`、`else`、`finally` 的执行顺序理解不够透彻，尤其是 `else` 与 `finally` 的触发时机容易混淆；在捕获异常时，对异常类型的区分不够精准，有时会捕获过宽或过窄；
-   **模块与包的调用**：对内部模块与外部模块的区分不够清晰，偶尔会忘记外部模块需要先 `pip install` 安装；对 `import` 的几种写法（如 `import 模块`、`from 模块 import 函数`）的使用场景掌握不够熟练；
-   **调用大模型**：对「请求—响应」的完整流程理解不够深入，尤其是请求参数的构造（如 `messages` 的格式、`model` 的选择）以及响应数据的解析（如 `choices` 的层级结构）容易出错，需要多写几个示例来加深理解。

#### 2\. 改进措施

针对上述薄弱点，我制定了以下改进计划：

-   多写异常处理的练习，重点对比 `else` 与 `finally` 的触发时机，并练习针对不同异常类型（如 `ValueError`、`FileNotFoundError`、`ZeroDivisionError`）的精准捕获；
-   整理模块与包的笔记，区分内部模块与外部模块，练习 `import` 的多种写法，并熟悉 `pip install` 的安装流程；
-   多写调用大模型的示例，反复练习请求参数的构造和响应数据的解析，加深对「请求—响应」流程的理解；
-   建立错题本，定期回顾，避免在同一个知识点上重复犯错。

#### 3\. 总结

本周的学习让我认识到，编程能力的提升是一个「理论—实践—反思」的循环过程。异常处理、模块调用是基础功，AI 大模型调用是面向未来的新技能，而项目一则是检验综合能力的最佳舞台。通过反思异常处理、模块与包以及调用大模型的学习，我意识到这些进阶知识虽然有一定难度，但只要把执行流程、调用方式和请求响应机制理解透彻，就能在项目中灵活运用。我的英雄信息管理系统虽然功能不算复杂，但通过增删改查、txt 持久化和语音播报的整合，让我真正体会到了「把需求变成代码」的完整过程。接下来我会继续完善项目，同时补强这些进阶知识点，争取在细节上做得更精致。
